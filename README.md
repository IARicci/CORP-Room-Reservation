# Megawide Room Reservations – testing site

Ready to publish on Netlify. There is no build step.

- `index.html` – the portal (client demo build with sample data and the phone/iPad apps)
- `netlify.toml` – Netlify settings

Upload these files to the top level of a GitHub repository and connect it to Netlify, or drag this folder onto https://app.netlify.com/drop.

After it publishes, open `/#apps` for the phone and iPad app QR codes.
